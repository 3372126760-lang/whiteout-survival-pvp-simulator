# 车身技能选择：效果摘要与搜索

更新：2026-10-06。本轮只修改展示层，技能定义、战斗适配和保存格式保持原实现。

## 使用方式

集结 A／B 方的四个车身槽各自提供搜索框和原生下拉列表，支持键盘选择。

- 列表按攻击、防御、穿透、生命、增伤、减伤、易伤／抗性、场景特化、控制／特殊机制分类。
- 每项显示效果摘要与具体英雄，例如 `全军攻击提升25%（SR书允）`、`全军攻击提升25%（S7布拉德利）`、`敌方防御降低25%（S8亨德里克）`。
- 同效果英雄相邻显示，但各自保留原始技能 ID；选项不会合并成一个身份不明确的代表英雄。
- 搜索支持英雄名、技能名、效果、数值、稀有度和赛季，如 `攻击`、`25%`、`书允`、`S7`；多个关键词按同时满足筛选。`SR` 不会误匹配 `SSR`，全角数字／百分号可搜索。
- 筛选不自动选择英雄。已选英雄不匹配关键词时，仍保留在“当前选择（未匹配搜索）”分组中；无匹配项会显示明确提示。
- 选中后显示英雄名、稀有度／赛季、中文远征一技能名、当前等级效果、触发说明和完整技能说明。长摘要可在详情中阅读，选项同时提供 title 次级说明。

未选技能按默认 Lv5 展示；已选技能按实际保存等级展示，例如书允 Lv3 显示攻击提升15%，不会沿用目录的 Lv5 25% 摘要。概率、持续时间、下一回合生效、兵种／伤害类型范围、周期等由现有技能定义派生，不把概率增益显示成常驻增益，也不把敌方防御降低显示成减伤。完整技能说明保留数据中的原文，当前等级数值单独标明。

## 数据与边界

`src/ui/bodySkillPresentation.ts` 生成 UI 专用数据：`heroId`、`heroName`、`rarity`、`generation`、`skillId`、`skillName`、`skillDescription`、`level`、`category`、`effectSummary`、`displayLabel`、`timingSummary`。

来源为现有 ServerStage 可用车身目录、正式英雄远征一技能和当前等级的 effect metadata。只展示允许 member 的远征一技能，不引入专武、二／三技能或英雄静态属性。手动列表继续允许现有 R/SR 车身；本轮没有改变优化器候选规则。

`src/ui/bodySkillSelectView.ts` 负责分类选项、详情和搜索状态展示。`main.ts` 沿用原 `data-scope="member"`、原始 skillId、`updateMember` 和现有存储流程。四槽重复英雄选择仍可用，技能等级沿用原选择逻辑。

搜索词只在 UI 内存中保存；输入搜索时仅更新当前槽的选项和计数，不重建整页、不触发自动保存、不改 BattleInput、不清空模拟结果。刷新后搜索词重置；车身选择按原格式正常恢复。
