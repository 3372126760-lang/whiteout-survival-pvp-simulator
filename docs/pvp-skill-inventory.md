# PVP 技能总清单

> **历史快照，不作为 2026-09-27 最新规则的实现清单。** 下表仍保留旧 `baseDamageIncrease`、`normalAttackDamageIndependent`、`skillDefenseBonus` 及直接抵消等名称和当时的证据描述。当前分组、逐级 effect 和验证边界请使用 [全量英雄技能报告](../hero_skill_inventory.md)、[乘区表](pvp-multiplier-groups.md) 和 [最新迁移清单](../PVP_RULE_MIGRATION_2026-09-27.md)。

> 审计日期：2026-09-22；兵种规则同步：2026-09-24。`confirmed` 只表示存在独立于当前实现的明确证据，足以确认 effect 当前 group/机制；代码本身、名称类比或“运行正常”均不构成确认依据。

## 字段说明

- 每个技能只列一次；一个技能的多个 effect 在同一单元格逐项拆开。技能行的确认状态是其全部 effect 状态的聚合；逐 effect 的 `confirmationBasis` 见本文后半部分与 JSON。
- `source/target/damage/subtype` 来自当前 effect scope；省略维度按 `all`。
- 生命周期依次显示 activation、duration、period、activeRounds、refresh、maxStacks。
- 专武技能属于同一 `HeroSkillDefinition` 注册表，标记为 `exclusiveWeapon`；非战斗远征技能也保留，但不计入 PVP effect 数。
- 本轮 S1/S2 与全局属性规则同步后，技能属性 group（包括保留旧 ID 的 `heroAttackBonus` 等）均为面板 factor 之外的乘区：同组先加算，再与 `(1+panelAttribute)` 相乘。机器清单的 `operation` 表示运行时语义；S3+ 原定义若仍写 `addToAttribute`，会额外保留 `declaredOperation` 供审计。
